# Neural Network from Scratch

This is a small project about neural networks and backpropagation that I did in school. It uses the MNIST database to learn handwriting recognition. The whole neural network was built from scratch in Delphi 10.2 without using any external libraries.

The implementation itself is pretty basic and lacks a lot of features you would want from a neural network, like automatic calculation of the validation accuracy and so on. But all in all, it works, and considering it was just an educational project, it was pretty cool, even though it was written in one of the most inappropriate programming languages for this use case.
